# タスク管理アプリ

シンプルなカンバン式タスク管理アプリです。フロントエンド（`index.html`）はビルド不要ですが、データはバックエンドAPI（`backend/`、Spring Boot + PostgreSQL）に保存するため、**利用前にバックエンドとDBコンテナを起動しておく必要があります**。

## 起動手順

```
docker compose up -d   # PostgreSQLコンテナ起動（リポジトリ直下で実行）
cd backend
mvn package
java -Xmx256m -Xss512k -XX:MaxMetaspaceSize=128m -jar target/task-manager-api-0.1.0.jar
```

ビルドと起動には JDK 25 が必要です。バックエンドが `http://localhost:8080` で起動した状態で、ブラウザで **`http://localhost:8080/`** を開いてください（`mvn package` 時にフロントエンド一式がバックエンドの静的リソースとして同梱されます）。バックエンドに接続できない場合は画面上部に赤いエラーバナーが表示されます。詳細な起動方法・API仕様は [`backend/README.md`](./backend/README.md) を参照してください。

**注意:** `index.html` を `file://` で直接（ダブルクリックで）開くと、ログイン機能が正しく動作しません。ブラウザはCookieのSameSite制限により、`file://` ページから `http://localhost:8080` への通信でセッションCookieを送信しないため、ログインしてもボードが表示されなかったり、リロードのたびにログアウト状態に戻ったりします。必ず `http://localhost:8080/` 経由で開いてください。

## 使い方

1. バックエンドを起動した状態で `http://localhost:8080/` をブラウザで開き、「新規登録」または「ログイン」する（初回ログイン時は「マイボード」が自動作成される）
2. 「+ タスク追加」からタイトル・詳細・ステータス・期限・優先度・カテゴリ・チェックリストを入力
3. カードをドラッグ&ドロップして列間を移動、列内でも自由に並び替え可能。タッチ端末などドラッグが使いづらい場合は、カードを開いて「ステータス」欄から列を選び直すこともできる
4. カードをクリックすると編集・削除ができる。カード左上のチェックボックスで完了/未完了を切り替え（完了済みは取り消し線で表示）
5. 列見出しをクリックすると列名を変更、見出しの✓ボタンでその列を「完了扱い」に切り替え（完了扱いの列に入ったタスクは期限超過表示をしない）、末尾の「+ 列を追加」で新しい列を作成（追加時に完了扱いにするかも指定可）。列見出しの名前部分はドラッグ&ドロップで列自体の並び替えにも使える
6. ヘッダーの検索欄でタイトル・詳細をキーワード検索、セレクトでカテゴリ・優先度による絞り込みが可能。絞り込み中はヘッダー下に「全N件中 M件を表示」と「条件をクリア」ボタンが出る
7. 「並び替え」セレクトで表示順を手動/期限順/優先度順に切り替え（期限順・優先度順を選んでいる間は列内のドラッグ並び替えは無効、列間の移動は可能）
8. 「⚙ 設定・データ」メニューのテーマボタンで自動（OS追従）/ライト/ダークを手動切り替え
9. 同じメニューの通知ボタンでブラウザ通知を許可すると、期限当日・期限超過のタスクがある日に1回通知が届く
10. ヘッダー左上のボード切り替えセレクトと+/✎/×ボタンで、ボード（カンバン一式）を複数作成・名称変更・削除できる。ボードごとに列とタスクは独立している
11. ヘッダーの「☑ 選択」で選択モードに入り、カードをクリックして複数選択 →「選択したタスクを削除」でまとめて削除（「表示中をすべて選択」「完了済みを選択」も可。検索・フィルタで見えていないタスクは選択対象外。Escキーまたは「終了」で選択モードを抜ける）
12. 「⚙ 設定・データ」メニューの「エクスポート」で現在のボードのタスク・列一式をJSONファイルにダウンロード、「インポート」で読み込んで現在のボードへ復元・移行
13. キーボードショートカット: `N` でタスク追加、`/` で検索欄へ移動、`Esc` でモーダル・メニュー・選択モードを閉じる。Tabキーでカードにフォーカスし、Enterで開く

## 機能

### アカウント
- メールアドレス・パスワードでのユーザー登録/ログイン/ログアウト（Cookieセッション、パスワードはBCryptでハッシュ化）
- アカウント設定からメールアドレス・パスワードを変更（現在のパスワードで本人確認）。パスワードを変更すると、他の端末・ブラウザはログアウトされる
- ログインが切れた（他の端末でパスワード変更・サーバー再起動など）ときは、自動でログアウト状態の画面に戻り、再ログインを案内する
- パスワード入力欄の表示/非表示切り替え、登録・ログイン時の確認入力
- ボード・列・タスクはユーザーごとに分離され、他ユーザーのデータにはアクセスできない

### ボード・列
- ボードを複数作成し、用途ごとに列・タスクを分けて管理（作成・名称変更・削除。削除時はそのボードの列・タスクも削除）
- カンバンの列をカスタマイズ（追加・名称変更・削除・ドラッグ&ドロップ/◀▶ボタンでの並び替え）
- 列ごとに「完了扱い」を設定でき、完了扱いの列では期限超過表示をしない

### タスク
- タスクのCRUD（追加・編集・削除）と、サブタスク/チェックリスト（進捗 n/m 表示）
- 完了/未完了の切り替え（カード上のチェックボックス、またはモーダル）。完了済みは取り消し線・半透明で表示
- ドラッグ&ドロップでの列間移動・列内の手動並び替え。モーダルの「ステータス」欄からもドラッグなしで列移動可能（タッチ端末向け）
- 期限・優先度（高・中・低）の管理。期限超過は強調表示、期限が2日以内のタスクは「今日まで」「明日まで」「あさってまで」とオレンジで表示（今年以外の期限は年も表示）
- カテゴリ/タグ（カンマ区切りで複数、タグごとに色分け）
- 作成日をモーダルに表示
- 選択モードによるタスクの一括削除（「表示中をすべて選択」「完了済みを選択」も可能）

### 表示・検索
- タイトル・詳細のキーワード検索、カテゴリ・優先度での絞り込み（絞り込み中は表示件数と「条件をクリア」ボタンを表示）
- キーボード操作（`N` タスク追加 / `/` 検索 / `Esc` 閉じる、Tab・Enterでカードを開く、フォーカス位置の枠表示）
- 表示順を手動/期限順/優先度順から選択
- テーマの手動切り替え（自動/ライト/ダーク）。「自動」時はOSのライト/ダークテーマに追従
- スマホ幅にも対応（列の削除・完了扱いボタンはタッチ端末でも常時表示）

### 通知・データ
- 期限当日・期限超過のタスクをブラウザ通知で知らせるリマインダー（通知ボタンで有効化、1日1回）
- JSONによるエクスポート/インポート（ボード単位でのバックアップ・別環境への移行）
- バックエンドAPI（PostgreSQL）へ自動保存。接続できないときは画面上部にエラーバナーを表示
- `file://` で開いた場合は正しいURLへの案内を表示

## 技術構成

フロントエンドは素のHTML / CSS / JavaScriptのみで、フレームワークやビルドツールは使用していません。バックエンドはSpring Boot REST API（`backend/`、詳細は[`backend/README.md`](./backend/README.md)参照）。

| ファイル | 役割 |
|---|---|
| `index.html` | 画面構造 |
| `style.css` | スタイル |
| `app.js` | タスクの状態管理・描画、バックエンドAPIとの通信 |
| `requirements.html` | 要件定義書 |
| `docs/finance-app-requirements.md` | 派生アプリ（収支管理アプリ）の要件定義書 |
| `mockup.html` | UIモックアップ（style.cssを読み込んだ静的な画面サンプル、操作不可） |
| `architecture.html` | 画面遷移図・データモデルER図・APIシーケンス図 |
| `backend/` | Spring Boot REST API（Board / Column / Task） |
| `docker-compose.yml` | バックエンド用PostgreSQLコンテナ定義 |

## データ保存について

タスク・列・ボードはすべてバックエンドAPI経由でPostgreSQLに保存されます（`docker-compose.yml`のDBコンテナ）。テーマ・通知設定・「最後に開いていたボード」の記憶のみ、ブラウザの`localStorage`に保存される端末固有の表示設定です。別環境へタスクデータを持ち出す場合は「エクスポート」でJSONを書き出し、移行先で「インポート」してください（インポートは現在のボードのデータを全置換します）。

## バックエンド

`backend/` に、Spring Boot REST API（Java 25 / Spring Boot 4.1.1）を用意しています。本番/開発ではPostgreSQL（Dockerコンテナ）、テスト実行時はH2インメモリDBを使用します。詳細は [`backend/README.md`](./backend/README.md) を参照してください。

## PostgreSQLコンテナ（Docker）

リポジトリ直下の `docker-compose.yml` で、`backend/` のSpring Boot APIが使用するPostgreSQLコンテナ（`taskmanager` データベース）を起動できます。

```
docker compose up -d   # 起動（localhost:5432、ユーザー/パスワード: taskmanager）
docker compose down    # 停止（データはボリュームに保持）
```

低メモリ環境向けに `postgres:16-alpine` を使用し、コンテナのメモリ上限を256MBに制限しています。バックエンドの起動方法は [`backend/README.md`](./backend/README.md) を参照してください。

## AWS（EC2）環境

`infra/terraform/` に、AWSの無料枠の範囲でEC2とRDS（PostgreSQL）を1台ずつ作るTerraformの設定があります。作り方・費用の注意点は [`infra/terraform/README.md`](./infra/terraform/README.md) を参照してください。

## 派生アプリの計画：収支管理アプリ

このアプリをベースに、個人向けの収支管理アプリ（「袋分け家計簿」をカンバンで作るイメージ）を作る計画があります。要件定義書は [`docs/finance-app-requirements.md`](./docs/finance-app-requirements.md) を参照してください。

- ボード → 家計簿、列 → カテゴリ（収入/支出）、タスク → 取引（金額・日付・メモ）に置き換える
- 金額は日本円の整数で保持し、集計はDB側で行う
- フェーズ1（MVP）：取引の記録、月の切替、収入・支出・残高のサマリー
- フェーズ2：CSV出力、月間予算、集計グラフ ／ フェーズ3：固定費の自動作成、予定と実績
